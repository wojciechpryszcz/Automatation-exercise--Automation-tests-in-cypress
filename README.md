Projekt testów Cypress
Wymagania
Node.js (wersja min. 16+)

Instalacja
Sklonuj repozytorium: git clone [link]

Wejdź do folderu projektu.

Zainstaluj zależności: npm install

Uruchomienie testów
Aby otworzyć interfejs Cypressa: npx cypress open

Aby uruchomić testy w trybie headless: npx cypress run
Test Casy pisane są wg scenariuszy dostępnych na stronie https://automationexercise.com/test_cases
